# Handwritten Digit Recognition using CNN

A deep learning project that recognizes handwritten digits (0-9) using a Convolutional Neural Network (CNN). The model is trained on image data and deployed using Streamlit.

## 🚀 Live Demo

Try the application here:

👉 [https://handwritten-digit-recognition-cnn-j4oulnydcvg7kmmaenmxlm.streamlit.app](https://handwritten-digit-recognition-cnn-bk5p2ibyfyixah76ednqta.streamlit.app/)

## Features

- Predicts handwritten digits from uploaded images
- Built using Convolutional Neural Networks (CNN)
- Simple and interactive Streamlit interface
- Real-time digit prediction
- Easy to use and deploy

## Installation

Clone the repository:

```bash
git clone https://github.com/Himanshu-97-cloud/Handwritten-Digit-Recognition-CNN.git
```

Move into the project folder:

```bash
cd Handwritten-Digit-Recognition-CNN
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the Streamlit app:

```bash
streamlit run streamlit_app.py
```

---

## How It Works

1. Upload a handwritten digit image.
2. The image is preprocessed.
3. The trained CNN model predicts the digit.
4. The prediction is displayed instantly.

---

## Dataset

This project uses the MNIST Handwritten Digits Dataset.

- 70,000 grayscale images
- Digits from 0 to 9
- Image size: 28 × 28 pixels
